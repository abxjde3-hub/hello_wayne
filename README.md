> Driver de kernel Linux completo com 3 subsistemas, monitoramento de sistema e interface unificada. Do Hello World ao nível de driver profissional.

![Kernel](https://img.shields.io/badge/Kernel-6.8+-yellow) ![License](https://img.shields.io/badge/License-GPL--2.0-blue) ![Level](https://img.shields.io/badge/Level-7.4%20FINAL%20BOSS-red)

### 🏆 O que foi conquistado

Este projeto evoluiu de um simples `printk` até um driver completo implementado em 7 níveis:

| Level | Feature | Subsistema |
|-------|---------|------------|
| 1 | Hello World | `printk` |
| 2 | Parâmetro customizável | `module_param` |
| 3 | Leitura de RAM e Uptime | `si_meminfo`, `ktime` |
| 4 | Lista de processos do sistema | `for_each_process` |
| 5 | Escrita via userspace | `procfs` writable |
| 6 | Char Device profissional | `cdev`, `alloc_chrdev_region`, `class_create` |
| **7.4** | **Interface Tripla Completa** | **procfs + devfs + sysfs unificados** |
