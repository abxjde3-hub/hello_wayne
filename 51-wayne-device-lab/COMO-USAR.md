# Wayne Device Lab - Como Usar
Passo 1: abrir so dentro do lab, lab-casa ou lab-loja.
Passo 2: escolher o aparelho, so seu aparelho autorizado.
Passo 3: pedir permissao, em portugues, na tela.
Passo 4: esperar o cliente falar sim para conectar.
Passo 5: tela mostra conectado, botao desconectar visivel.
Passo 6: terminar, apertar desconectar, apaga a conexao.
Se o cliente falar nao, desliga na hora, sem insistir.
