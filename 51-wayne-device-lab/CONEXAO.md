# Wayne Device Lab - Conexao
So conecta dentro do lab, lab-casa ou lab-loja.
So no Wi-Fi autorizado, fora do lab bloqueado.
So conecta com permissao, em portugues, na tela.
So se o cliente falar sim, se falar nao desliga.
Quando conecta, mostra na tela que esta conectado.
Botao desconectar sempre visivel, bem grande.
Quando desconecta, apaga a conexao, nada fica ligado.
